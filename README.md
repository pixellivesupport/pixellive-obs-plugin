# Pixel Live OBS Plugin

Official OBS Studio plugin for **Pixel Live**.

Connect Pixel Live to OBS Studio and receive your live video stream directly from your Android device.

## ✨ Features

- 📡 Pixel Live SRT streaming integration
- 🔎 Automatic OBS discovery on the local network
- 🎥 Pixel Live source for OBS Studio
- ⚡ Fast and simple local network setup
- 🖥️ Designed for OBS Studio on Windows

## 📥 Download

**Pixel Live OBS Plugin v1.1 (5)**

## 🛠️ Installation

1. Download the installer.
2. Run `PixelLiveOBS.Setup.1.1.5.exe`.
3. Follow the installation instructions.
4. Start or restart OBS Studio.
5. Add **Pixel Live Source** to your OBS scene.
6. Open Pixel Live on your Android device and start OBS Discovery.
