# Pixel Live OBS Plugin

OBS Studio plugin that connects **Pixel Live** to OBS Studio.

Connect Pixel Live to OBS Studio and receive your live video stream directly from your Android device.

## ✨ Features

- 📡 Pixel Live SRT streaming integration
- 📱 Easy QR code pairing with the Pixel Live Android app
- 🎥 Dedicated Pixel Live source for OBS Studio
- ⚡ Fast and simple local network setup
- 🖥️ Designed for OBS Studio on Windows

## 🛠️ Installation

1. Download PixelLiveOBS.Setup...*.exe
2. Run the installer.
3. Follow the installation instructions.
4. Start or restart OBS Studio.
5. Add a **Pixel Live source** in OBS Studio. 
6. Open the Pixel Live Android app and scan the QR code to connect.
